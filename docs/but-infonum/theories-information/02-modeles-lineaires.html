LA THÉORIE DE L’INFORMATION DE SHANNON

Notions-clé : Source d’information : n’importe quelle entité produisant un message Transmetteur, ou codeur : met en forme le message de la source pour l’adapter au canal. Canal : support matériel de la communication (une ligne téléphonique, une transmission satellite, l’air, pour la voix, etc.) Récepteur, ou décodeur : restitue l’information émise par la source à partir de la sortie du canal Destinataire : n’importe quelle entité à qui est destiné le message

Source. AS

LA THÉORIE DE L’INFORMATION DE SHANNON

Notions-clé : Information : une information désigne un ou plusieurs événements possibles parmi un ensemble fini d’événements. L’information permet de diminuer l’incertitude. BIT : abréviation de binary unit (ou digit); unité de mesure de l’information, correspondant à la réduction de moitié de l’incertitude sur un problème donné « Yseult guette le retour de Tristan, la voile sera-t-elle blanche ou noire ? Théories de l’information · diapo 29

Quantité d’information : définie comme étant mesurée par le logarithme du nombre des choix possibles.

  • Quantité d’information : définie comme étant mesurée par le logarithme du nombre des choix possibles.
  • Exprimée en logarithme de base 2
  • La quantité d’information est définie ainsi :
  • Log2 (N ÷ n)
  • N = le nombre d’événements possibles dans un message
  • n = nombre d’événements d’un sous-ensemble de N

Les 6 fonctions : (Complémentaires, +- dominantes dans chaque message) Fonction référentielle (contexte) : « l’eau bout à 100 degrés » ; ce dont on parle… Fonction expressive ou émotive (destinateur) : « ce soir » répété 40 fois par un acteur russe Fonction conative (destinataire) : apostrophe, injonction, persuasion… ( conatif (linguistique :Qui (dans le message linguistique) a pour but de produire un certain effet sur le destinataire.) Fonction dominante de la publicité Fonction phatique (contact) : « allo » Dimension sociale de la communication Fonction méta-linguistique (code) : définitions, réglages de la communication.. Fonction poétique (message) : valeur du message pour lui-même ; Euphonie, assonances (« I like Ike »)
