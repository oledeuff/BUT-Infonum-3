# Site de visualisation — Titres de presse aidés en 2024 (v2)

## Nouveautés
- Les fiches affichent la **ventilation des montants par fonds** (pluralisme, distribution, exemplaire posté/porté, FSDP, FSEIP) directement sur la carte.
- Un bouton **Version claire / Version sombre** est disponible (mémorisé dans le navigateur).

## Utilisation
Ouvrez `index.html` dans un navigateur récent.

Si l’ouverture directe bloque les scripts, utilisez un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000/site_aides_2024_v2_fonds_theme/`.
